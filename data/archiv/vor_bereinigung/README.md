# Sicherung vor der Bereinigung

Unveraenderte Originale der Fonds-Dateien (trades, history, state) vom Stand vor `scripts/bereinigung.py`. Vorhandene Zeilen werden nie veraendert; neue Rohzeilen spaeterer Workflow-Laeufe werden nur ANGEHAENGT (append-only, siehe extend_archive). Pruefsummen: SHA256SUMS.txt. Die Bereinigung berechnet ihren Stand immer aus dieser Sicherung. Damit die Sicherung fuer sich konsistent bleibt, bucht das Anhaengen die Betraege auch auf die Kasse in den state-Dateien und entfernt Positionen, deren Lebenszyklus inzwischen geschlossen ist (Kasse = Start + Summe der Handelsliste, Positionen = offene Lebenszyklen).
